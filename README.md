# 〇〇接骨院 ホームページ

院のホームページです。予約システム（C:\dev\sekkotsu-yoyaku）とは別のサイトで、
「ネット予約はこちら」ボタンから予約システムの患者さん用ページへ移ります。

ログインやデータベースは使わない、HTML と CSS だけのサイトです。

## ファイル

- `index.html` … ページの中身（院名・紹介文・メニュー・診療時間・住所など）
- `style.css` … 見た目（色は先頭の `:root` で変える）
- `images/` … 写真を置く場所
  - `hero.jpg` … 一番上の大きな写真（置くだけで表示される。横長がおすすめ）
  - 院内の写真は好きな名前で置き、`index.html` の「院内の様子」の部分で指定する

## 確認

`index.html` をダブルクリックするとブラウザで見られます。

## 書き換えが必要な所（決まったら）

- 院名（`〇〇接骨院`）、紹介文、住所、電話番号、地図
- 予約ボタンの行き先（予約システムを公開したら、その URL に変える）
- 診療時間・メニューは予約システムの設定と自動ではつながっていないので、変えたときは両方直す
